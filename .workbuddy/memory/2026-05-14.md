# 2026-05-14

## Added batch upgrade support to CKAN-CLI

### What was done
- **`CLI/ActionExecutor.cs`** — Added two new action commands:
  - `[UPGRADE:identifier]` — Upgrades a specific mod to latest version using `ModuleInstaller.Upgrade()` + `NetAsyncModulesDownloader`
  - `[UPGRADE_ALL]` — Upgrades all outdated mods using `registry.CheckUpgradeable()`
- **`CLI/AiClient.cs`** — Updated system prompt with:
  - New UPGRADE/UPGRADE_ALL actions listed
  - Instructions for handling pasted mod lists (parse identifiers, don't echo, offer actions)
  - Batch/continuous execution instructions (process one by one, auto-continue, report summary)
- **`CKAN-CLI.md`** — Added UPGRADE and UPGRADE_ALL to docs table

### User request
User wanted AI to handle pasted mod lists properly — not just echo them back, but parse identifiers and perform batch operations continuously (update all, etc.) without stopping after each one.
